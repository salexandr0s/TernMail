# ChatGPT artwork in Tern

The `ChatGPTLogo` asset contains the original black and white SVG files published by OpenAI for Sign in with ChatGPT. The files were downloaded on 2026-10-30 and are stored unchanged:

- [Black logo](https://developers.openai.com/assets/siwc/sign-in-buttons/chatgpt-logo-black.svg), SHA-256 `b8b9aba7ba591f54bf1805f422bc23f32c44ee993643cc378cc77f766061f7a1`.
- [White logo](https://developers.openai.com/assets/siwc/sign-in-buttons/chatgpt-logo-white.svg), SHA-256 `568ce2e8701934856aaafc0ed1c3d0300f6c2ff384d0ae743dd1dea08570e12c`.

The assets identify the ChatGPT connection in Tern and its sign-in action. `ChatGPTBrand` selects an original black or white variant for contrast, keeps the square aspect ratio, and adds no color or visual effects. The button uses the approved **Continue with ChatGPT** label and a monochrome background, with native system typography, focus feedback, and Tern's spacing tokens.
